list

GET /plannedWorkouts

Operation ID: Workouts_ListPlannedWorkouts.

Authentication: API key in the header (ApiKeyAuth) or API key in the header (DevID).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | user_id | query | string | Yes | | | start_date | query | string (date) | No | Start of the planned-date window (YYYY-MM-DD). When start_date and end_date are omitted, provider-side workouts default to the trailing 30 days; pass an explicit window to list upcoming workouts. | | end_date | query | string (date) | No | End of the planned-date window (YYYY-MM-DD), inclusive. |

Responses

200: Planned workouts for the connection

application/json

Property Type Required Description
[].athlete_metrics object or null No
[].coercion_warnings string or null No Warnings emitted when the template could not be represented exactly on the provider
[].created_at string or null No Creation time (RFC 3339)
[].details object or null No Full workout body (title, description, planned metrics, structured steps) fetched live from the provider. Present only for external workouts (is_external true).
[].is_external boolean or null No True when the workout was created on the provider side rather than through Terra
[].last_updated_at string or null No Last update time (RFC 3339)
[].planned_date string or null No Scheduled date (YYYY-MM-DD)
[].planned_workout_id string or null No Terra identifier of the planned workout
[].provider_workout_id string or null No Identifier of the workout on the provider's side, once pushed
[].workout_id string or null No Identifier of the workout template this was planned from. Absent for workouts created on the provider side.
