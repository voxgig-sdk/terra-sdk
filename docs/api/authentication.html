POST /auth/authenticateUser

Operation ID: Authentication_AuthenticateUser.

Authentication: API key in the header (ApiKeyAuth) or API key in the header (DevID).

Parameters

Parameter In Type Required Description
resource query string Yes Provider resource identifier (for example, 'FITBIT', 'GARMIN', 'OURA'). See "Get detailed list of integrations" for available providers
dev-id header string Yes your developer ID

Request body

application/json

Property Type Required Description
auth_failure_redirect_url string No
auth_success_redirect_url string No
language string No
reference_id string No
sdk_app enum: avengers, grip No Which Terra reference app an SDK authentication link hands the end user to. For APPLE_HEALTH, omit to use Terra Avengers. For HEALTH_CONNECT and SAMSUNG, "grip" is required; any other value or omitting it is rejected with a 400. The link carries a resource query parameter (APPLE, HEALTH_CONNECT or SAMSUNG) naming the connection the app opens. Sending this for any other resource has no effect.

POST /auth/generateWidgetSession

Operation ID: Authentication_GenerateWidgetSession.

Authentication: API key in the header (ApiKeyAuth) or API key in the header (DevID).

Request body

application/json

Property Type Required Description
apple_app_url string No URL of your own iOS app to hand Apple Health connections to, instead of the Terra mobile app
auth_failure_redirect_url string No URL the user is redirected to upon unsuccessful authentication
auth_success_redirect_url string No URL the user is redirected to upon successful authentication. The legacy value multi-auth is honoured and sets multi_auth instead of acting as a URL.
bypass_feedback boolean No When false, the user stays on the widget's own result screen instead of being redirected immediately
connected_uids array of string No Terra user IDs already connected for this end user; their providers show as connected with a disconnect option
language string No forces the widget UI language (for example en, fr, ja, zh_cn); unsupported codes fall back to the end user's browser language
multi_auth boolean No Keep the user on the widget after each successful connection so they can connect several providers in one session
providers string No Comma separated list of providers to display on the device selection page. The legacy wildcard ALL means every provider enabled on your dashboard, the same as omitting the field.
reference_id string No Identifier of the end user on your system, such as a user ID or email associated with them
samsung_app_url string No URL of your own Android app to hand Samsung Health connections to
show_disconnect boolean No Show disconnect buttons for providers already connected under reference_id
use_terra_avengers_app boolean No Allow Apple Health connections through the Terra mobile app

Responses

200: Returned when authentication link could be successfully generated

application/json

expires_in number No a number in seconds depicting how long the url is valid for

url string No the widget URL the user must be redirected to in order to link their account
warnings array of string No present when part of the request could not be honoured, such as requested providers that are unknown or not enabled
