Operation ID: User_List.

Authentication: API key in the header (ApiKeyAuth) or API key in the header (DevID).

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | page | query | integer | No | Zero-based page number. If omitted, results are not paginated. | | per_page | query | integer | No | Number of results per page (default is 500). |

200: Returned upon a successful request

application/json
